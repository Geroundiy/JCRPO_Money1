# 💰 Денежная капсула (Money Capsule)

Java Spring Boot PostgreSQL JavaScript

**Денежная капсула** — это веб-приложение для управления личными финансами, которое помогает пользователям не просто фиксировать доходы и расходы, а осознанно накапливать средства на конкретные цели. Система поддерживает мультивалютный учет, автоматическую конвертацию по актуальным курсам и визуализирует прогресс достижения финансовых целей.

## 🚀 Возможности

### 🎯 **Управление целями**

  * Создание финансовых целей с указанием суммы, валюты и дедлайна
  * Визуализация прогресса («наполнение капсулы» и прогресс-бар)
  * Расчет оставшейся суммы и времени до достижения цели
  * Поддержка валют: BYN, USD, EUR, RUB

### 💳 **Учет операций**

  * Фиксация доходов и расходов
  * Категоризация тракт (Еда, Транспорт, Развлечения и др.)
  * Автоматическая проверка баланса (защита от ухода в минус)
  * История транзакций с сортировкой по дате
  * Мгновенное обновление статистики без перезагрузки страницы

### 💱 **Мультивалютность**

  * Интеграция с API Беларусбанка для получения курсов в реальном времени
  * Автоматическая конвертация всех операций в валюту цели
  * Встроенный калькулятор-конвертер валют
  * Кеширование курсов для быстрой работы при нестабильном соединении

### 👤 **Безопасность и профиль**

  * Регистрация и аутентификация пользователей
  * Хеширование паролей (BCrypt)
  * Изоляция данных (пользователь видит только свои записи)
  * Безопасное хранение сессий

### 🎨 **Современный интерфейс**

  * Single Page Application (SPA) архитектура
  * Адаптивный дизайн (Desktop/Mobile)
  * Переключение темной и светлой темы (Dark Mode)
  * Интерактивная SVG-анимация копилки
  * Фоновое видео для темной темы

## 🛠️ Технологический стек

### Backend (Java)

  * **Framework:** Spring Boot 3.2.0
  * **Language:** Java 17
  * **Security:** Spring Security
  * **Database:** PostgreSQL
  * **ORM:** Spring Data JPA (Hibernate)
  * **API Client:** RestTemplate

### Frontend

  * **Core:** HTML5, CSS3
  * **Logic:** Vanilla JavaScript (ES6+)
  * **Architecture:** MVC / SPA elements
  * **Styling:** Custom CSS + Tailwind (частично для форм входа)

## 🚀 Быстрый старт

### Требования

  * Java 17+
  * PostgreSQL
  * Maven

### 1\. Клонирование репозитория

```bash
git clone https://github.com/Geroundiy/JCRPO_Money1.git
cd JCRPO_Money1
```

### 2\. Настройка базы данных

Создайте базу данных PostgreSQL с именем `fieldcontrol_db`.
Отредактируйте файл `src/main/resources/application.properties`, указав ваши данные:

```properties
spring.datasource.url=jdbc:postgresql://localhost:5432/fieldcontrol_db
spring.datasource.username=ВАШ_ЛОГИН
spring.datasource.password=ВАШ_ПАРОЛЬ
```

### 3\. Сборка проекта

```bash
mvn clean install
```

### 4\. Запуск приложения

```bash
mvn spring-boot:run
```

Приложение будет доступно по адресу `http://localhost:8080/`

## 📚 API и маршруты

### Аутентификация

  * `POST /api/auth/register` - Регистрация нового пользователя
  * `POST /api/auth/login` - Вход в систему
  * `POST /api/auth/logout` - Выход

### Данные и операции

  * `GET /api/data` - Получение всех данных пользователя (цель, транзакции)
  * `POST /api/data/goal` - Создание или обновление цели
  * `DELETE /api/data/goal` - Удаление цели и очистка истории
  * `POST /api/data/transaction` - Добавление дохода или расхода

### Валюта

  * `GET /api/currency` - Получение актуальных курсов валют (кешируется на 5 минут)

## 🔧 Конфигурация

### Настройки приложения

Основные параметры находятся в `application.properties`:

  * `server.port` - Порт сервера (по умолчанию 8080)
  * `spring.jpa.hibernate.ddl-auto` - Стратегия создания таблиц (update)
  * `spring.datasource.*` - Параметры подключения к БД

## 🎯 Основные функции

### Начало работы

1.  Зарегистрируйтесь и войдите в систему.
2.  Нажмите кнопку меню `+` -\> `🎯` (Настроить цель).
3.  Задайте название, сумму и валюту накопления.

### Ведение бюджета

1.  **Доход:** Нажмите `+` (оранжевая кнопка), введите сумму. Капсула начнет заполняться.
2.  **Расход:** Нажмите `-` (красная кнопка), выберите категорию. Сумма вычтется из накоплений.
3.  **Конвертер:** Нажмите `💱` для быстрого пересчета валют по курсу банка.
